# 深职大香蜜校区｜创新创意设计艺术学院校园指南（H5）

移动端竖屏 H5 校园指南，采用**单页（SPA）结构**：整个项目**只有唯一入口 `index.html` 一个页面（唯一网址 `/`）**，彻底取消独立的 `admin.html` 后台页面。前台「首页 / 吃什么 / 学什么 / 玩什么」四大浏览区块，与**内嵌在同一页面里的管理员后台**（登录鉴权、首页 / 专业板块 / 玩乐分类 / 美食 / 学习资料 / 社团组织 六大模块的增删改与审核）共存于同一网址，通过 JS 在同一页面内切换展示，全程不跳转、不开第二个页面。学生投稿进入待审核，审核通过后前台即时展示。

## 技术栈
- 前端：HTML + TailwindCSS（CDN 引入，无需构建）
- 后端：Node.js + Express
- 数据库：SQLite 单文件（`data.db`，由 Node 内置 `node:sqlite` 驱动，无需额外编译）

## 目录结构
```
campus-guide/
├── server.js          # Express 服务入口（托管前端 + 提供接口）
├── db.js              # SQLite 单文件数据库数据层（含种子数据）
├── package.json
├── data.db            # 运行时自动生成的数据库文件（首次启动创建）
├── README.md
├── test-mobile.md     # 手机访问测试指南（同一 Wi-Fi 真机访问步骤）
└── public/            # 前端 H5（单页，唯一入口）
    └── index.html     # 唯一页面：含前台四大浏览区块 + 内嵌管理员后台（登录弹窗 + 六大模块，同一网址内切换，无独立后台页）
```

## 启动步骤
> 要求 Node.js ≥ 18（推荐 20+，本机为 v22，已内置 node:sqlite）。

1. 安装依赖（仅需一次）：
   ```bash
   cd campus-guide
   npm install
   ```
2. 启动服务：
   ```bash
   npm start
   # 或： node server.js
   ```
3. 浏览器访问（**全程只有一个网址**）：
   - 首页 / 前台浏览： http://localhost:3000/ —— 在首页点击「吃什么 / 学什么 / 玩什么」卡片，单页内切换到对应区块；每个区块顶部「‹」返回首页
   - **管理入口**：首页右上角橙色「管理入口」按钮 → 弹出登录框（账号 admin / 密码 admin123）→ 登录后**同一页面内**切换为管理面板；管理面板顶部有「返回浏览模式」按钮切回学生视角
   - 已无任何独立后台页面或第二个网址（`/admin`、`/admin.html` 均已移除）

    建议用浏览器开发者工具的「手机模拟」查看竖屏效果；管理面板同样适配手机。

### 手机 / 局域网访问（同一份数据，双向同步）
- 后端监听 `0.0.0.0`，**允许局域网内其他设备（手机）访问**。手机与电脑连同一个 Wi-Fi，用手机浏览器打开：`http://<电脑局域网IP>:3000/`（例如 `http://192.168.1.20:3000/`）。
- 电脑端在后台改了内容（标题 / 轮播 / 简介 / 审核投稿等）写入同一个 SQLite 文件 `data.db`；手机端刷新页面即拉取最新数据，**两端共用同一份数据库，双向实时同步，不会各自存数据**。
- 查看电脑局域网 IP：`Windows 终端` 输入 `ipconfig` 看「IPv4 地址」；macOS 输入 `ifconfig | grep inet`。
- 注意：少数校园网/公司网会隔离设备间访问（AP 隔离），如遇手机连不上，请改用电脑开热点，或在同一路由器下测试。

### 跨网络访问（内网穿透 / 云服务器）
项目已内置 **CORS 跨域支持**，可直接用于内网穿透（ngrok / frp / 花生壳）或云服务器 / CDN 反代等跨网络、跨域场景，无需改动代码。

- **后端已开启 CORS**：自动镜像请求方 `Origin`，并允许携带凭证（`credentials`），同时正确处理 `OPTIONS` 预检。同源（本机 / 局域网 / 同域云服务器）场景不受影响，功能完全不变。
- **登录态 Cookie 自适应**：
  - 通过 HTTPS 访问（内网穿透 / 云服务器反代通常为 https）→ Cookie 自动设为 `SameSite=None; Secure`，使**跨域**也能携带登录态；
  - 纯 HTTP 访问（本机 / 局域网）→ 保持 `SameSite=Lax`，避免 `Secure` 导致 Cookie 无法写入而登录失效。
  - 判断依据为反向代理下发的 `X-Forwarded-Proto: https`，已 `app.set('trust proxy', true)`。
- **前端零硬编码**：所有接口请求均为相对路径（`fetch('/api/...')`），不写死任何 IP / 端口；换域名、换端口、走穿透隧道均无需改前端。
- **前端凭证模式**：`fetch` 统一使用 `credentials: 'include'`，同源照常工作，跨域也能携带登录态 Cookie。
- 部署要点：① 若仅单台服务器同时托管页面与接口（最常见）→ 同源，CORS 仅作兜底；② 若前端与接口分离到不同域名 → 需保持同源协议（建议都走 HTTPS），跨域登录态依赖上述 `SameSite=None; Secure`，因此**前端必须用 https 访问**才能写入登录 Cookie。

### 编辑密码（打破公网「纯只读」）
公网域名访问默认**只读**（隐藏全部编辑/投稿入口，防陌生人乱改）。若要远程也能编辑，项目内置一层**编辑密码**：

- **默认密码 `campus2026`**；可用环境变量覆盖：`EDIT_PASSWORD=你的密码 node server.js`（部署平台同理设环境变量）。
- **外部网络解锁**：页面底部出现「🔒 当前为只读模式 · 解锁编辑」条 → 点「解锁编辑」输入密码 → 验证通过即显示全部编辑/投稿按钮，可新增、修改、投稿。
- **解锁令牌**：后端下发 `edit_sid` Cookie（`httpOnly`，HTTPS 下自动 `Secure; SameSite=None`）；刷新页面经 `/api/network-mode` 自动保持已解锁状态，无需每次重输。点「退出编辑」调用 `/api/edit/lock` 可重新锁定为只读。
- **同一局域网（同 Wi-Fi）**：以电脑内网 IP 打开 → 自动判定为可编辑，**无需密码**，直接显示全部编辑入口（与公网只读互不冲突）。
- 后端门禁 `requireEdit` = `同一局域网 OR 已用编辑密码解锁`，未授权写操作统一返回 `403`；前端 `applyNetworkMode()` 同步显隐入口（纵深防御）。

详见 `test-mobile.md`（手机真机测试步骤）。

## 公开数据接口（前台调用）
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/carousel` | 轮播图列表（首页） |
| GET | `/api/intro` | 校区简介文字（首页） |
| GET | `/api/home-title` | 首页顶部大标题（首页） |
| GET | `/api/study-categories` | 专业板块列表（学什么标签栏） |
| GET | `/api/club-categories` | 玩乐分类列表（玩什么标签栏） |
| GET | `/api/foods` | 已发布美食（吃什么，不含待审核） |
| POST | `/api/foods` | 学生投稿美食 → 待审核 |
| GET | `/api/study` | 已发布学习资料（学什么，不含待审核） |
| POST | `/api/study` | 学生投稿学习资料 → 待审核 |
| GET | `/api/clubs` | 已发布社团/工作室（玩什么，不含待审核） |
| POST | `/api/clubs` | 学生投稿社团/工作室 → 待审核 |

投稿返回 `{ "id": 6, "status": "pending" }`；审核通过后才出现在对应前台列表。

## 管理员后台（内嵌于同一页面，无独立网址）
- **入口**：首页右上角橙色「管理入口」按钮 → 弹出登录框 → 登录后在同一页面内切换为管理面板（顶栏「返回浏览模式」可切回学生视角）。已删除独立的 `admin.html`，全程唯一网址为 `/`。
- 默认账号：**admin** ／ 密码：**admin123**（可用环境变量 `ADMIN_USER` / `ADMIN_PASS` 覆盖）
- 移动端优先适配，全部管理操作都可在手机上完成
- 登录态：会话 Cookie（`admin_sid`，7 天有效期）鉴权；前端首次加载会调用 `/api/admin/me`，已登录则自动进入上次视图（浏览/后台）。`/api/admin/*` 除登录 / 登出 / me 外均需登录
- 前端没有任何可直接修改文字/图片的入口，所有内容修改都收在后台面板
- 管理面板六大模块：①首页设置（标题/轮播/简介）②专业板块 ③玩乐分类 ④美食审核 ⑤学习资料审核 ⑥社团组织审核

## 单页区块分类标签（由后台管理）
- 页面为单页结构：`index.html` 内含「首页 / 吃什么 / 学什么 / 玩什么」四个区块，点击首页卡片 `showBlock('eat'|'study'|'play')` 切换显示，区块顶部「‹」调用 `showBlock('home')` 返回；原 `eat.html` / `study.html` / `play.html` 已删除。
- **学什么**：区块内顶部横滑专业分类标签栏（全部 + 后台配置的专业板块），点标签筛选；投稿「归属专业」下拉选项来自后台板块，提交时随 `category` 入库。
- **玩什么**：区块内顶部横滑分类标签栏（全部 + 后台配置的玩乐分类），点标签筛选；投稿「归属分类」下拉来自后台分类。
- 分类现已**由管理员后台维护**（专业板块可设封面图与简介），前台实时拉取，改完即生效。
- **审核即刷新**：前台在进入「吃什么 / 学什么 / 玩什么」任一区块时会自动重新拉取数据（`ensureLoaded` 每次进入都 `load()`），因此管理员在后台通过审核后，用户再次进入该板块即可看到新内容，无需刷新整页。
- 旧库通过 `db.js` 的 `migrateStudyCategory()` / `migrateClubsCategory()` 自动补全 `category` 字段。

## 移动端兼容性优化（已落地）
- **后端监听 `0.0.0.0`**：允许局域网内手机/其他设备访问；启动日志会提示用手机浏览器打开 `http://<电脑IP>:<端口>/`。
- **视口与全屏**：`<meta viewport>` 增加 `viewport-fit=cover`（适配刘海屏），锁定 `minimum/maximum-scale=1.0, user-scalable=no` 防止双击/捏合导致页面缩放错位；禁用页面横向溢出（`html,body{overflow-x:hidden}`）。
- **输入框不触发页面缩放**：全局 `input/textarea/select/button { font-size:16px }`，规避 iOS 输入框聚焦时整页自动放大（这是手机上"文字溢出/页面挤在一起"的核心原因）。
- **键盘遮挡修复**：所有弹窗（登录、投稿、后台编辑）面板加 `max-h + overflow-y-auto + modal-scroll`，输入法弹出时内容可上滑，输入框不被挡。
- **图片上传兼容手机相册**：所有上传控件改为「隐藏 `<input type=file>` + `<label for>` 触发」——规避 iOS Safari 在 `transform` 弹窗内直接点 input 无法弹出选择器的 BUG；按钮文案改为"📷 点击选择图片（支持相册多选）"，`accept="image/*"` 兼容拍照/相册。
- **触控目标放大**：后台所有编辑/删除/审核/新增/保存按钮、首页「管理入口」、返回浏览模式等统一加 `admin-btn`（最小高度 46px）；所有输入框加 `admin-input`（最小高度 46px），手指点击更友好。
- **单页架构不变**：仍为唯一入口 `index.html`，无新增页面、无新增网址。

## 获取固定链接（一键部署到 Render，零成本）

免费匿名穿透（ngrok / pinggy / localhost.run 免费档）的链接都会过期、地址随机，**无法固定**。要长期固定链接，请用云托管（本项目已配好一键部署）：

1. 把 `campus-guide/` 整个目录推到自己 GitHub 仓库（已含 `render.yaml`、`package.json` 的 `engines.node>=22` 与 `start` 脚本）。
2. 打开 [render.com](https://render.com) 注册（免费）→ **New Web Service** → 连接该 GitHub 仓库 → 直接识别 `render.yaml` 一键部署。
3. 部署完成后，Render 分配一个**固定子域名**（如 `https://campus-guide-xxxx.onrender.com`），永久不变、任何人手机/电脑直接打开即可。
4. 后台登录态、CORS、相对路径均已适配，部署后无需改任何代码。

> 注意：Render 免费版文件系统为临时盘，重启/重新部署后 `data.db` 会重置（演示数据回归初始）。如需内容长期保存，可在 Render 绑定 Postgres 或挂载持久磁盘——按需再配。
> 其他等价方案：Railway / Koyeb / Fly.io（同样免费额度 + 固定子域名）；或买域名 + 腾讯云/阿里云轻量服务器做完全自有域名。
